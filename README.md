# 🔐 مولّد كلمات المرور

صفحة ويب بسيطة لتوليد كلمات مرور قوية وعشوائية، بواجهة عربية من اليمين لليسار.
مكتوبة بـ HTML و CSS و JavaScript فقط، بدون أي مكتبات، وتعمل بالكامل داخل المتصفح.

**جرّبها مباشرة:** https://ilo0ol.github.io/password-generator/

## المزايا

- اختيار طول كلمة المرور من 8 إلى 32 حرفاً بشريط تمرير، مع عرض الرقم المختار.
- اختيار أنواع الأحرف: حروف كبيرة، حروف صغيرة، أرقام، رموز (كلها مفعّلة افتراضياً).
- خيار لاستبعاد الحروف المتشابهة: `0 O o 1 l I |`.
- عشوائية آمنة باستخدام `crypto.getRandomValues` بدلاً من `Math.random`.
- ضمان وجود حرف واحد على الأقل من كل نوع مختار.
- تنبيه واضح إذا لم يُختر أي نوع من الأحرف.
- توليد تلقائي عند فتح الصفحة وعند تغيير أي خيار.
- زر «توليد» وزر «نسخ»، ويظهر «تم النسخ ✓» بعد النسخ.
- مؤشر قوة ملوّن: ضعيفة / متوسطة / قوية / قوية جداً.
- تصميم نظيف يناسب الجوال أولاً، ويتحوّل للوضع الداكن تلقائياً حسب إعدادات الجهاز.

## طريقة الاستخدام

1. افتح الصفحة، وستظهر كلمة مرور جديدة فوراً.
2. حرّك شريط «الطول» لاختيار عدد الأحرف.
3. فعّل أو ألغِ أنواع الأحرف التي تريدها.
4. فعّل «استبعاد الحروف المتشابهة» إذا كنت ستقرأ كلمة المرور أو تكتبها يدوياً.
5. اضغط «توليد» للحصول على كلمة مرور أخرى بالإعدادات نفسها.
6. اضغط «نسخ» لنسخها إلى الحافظة.

لتسهيل القراءة، تظهر الأرقام والرموز بألوان مختلفة عن الحروف.

## كيف تعمل؟

### العشوائية

كل اختيار عشوائي يمر عبر `crypto.getRandomValues`، وهي واجهة المتصفح المخصّصة للعشوائية الآمنة تشفيرياً.
ولتجنّب انحياز باقي القسمة (modulo bias) تُرفض القيم التي تقع خارج أكبر مضاعف لحجم المجموعة ويُعاد السحب،
فيكون لكل حرف الاحتمال نفسه تماماً.

### ضمان وجود كل الأنواع المختارة

1. يُختار حرف واحد عشوائياً من كل نوع مفعّل.
2. تُكمَّل بقية الطول من مجموع الأحرف المتاحة.
3. تُخلط النتيجة بخوارزمية Fisher–Yates باستخدام المصدر العشوائي الآمن نفسه، حتى لا تكون الأحرف المضمونة في أماكن متوقّعة.

### مؤشر القوة

تُحسب القوة بوحدة «بت» من العشوائية، وتجمع بين الطول وتنوّع الأحرف:

```
القوة = الطول × log2(عدد الأحرف المتاحة)
```

| القوة بالبت | التقييم |
|---|---|
| أقل من 45 | ضعيفة |
| من 45 إلى 64 | متوسطة |
| من 65 إلى 89 | قوية |
| 90 فأكثر | قوية جداً |

أمثلة: 8 أحرف بكل الأنواع ≈ 52 بت (متوسطة)، و12 حرفاً ≈ 78 بت (قوية)، و16 حرفاً ≈ 103 بت (قوية جداً).

## الخصوصية

لا توجد خوادم ولا تتبّع ولا تخزين. كلمة المرور تُولَّد في متصفحك ولا تُرسل إلى أي مكان.

## التشغيل محلياً

افتح ملف `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً بسيطاً:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## هيكل المشروع

```
index.html   بنية الصفحة
style.css    التصميم ودعم الوضع الداكن
script.js    توليد كلمة المرور والنسخ ومؤشر القوة
```
